# 🍑 果然甜 — 訂單登記 Google Sheet + LINE 通知 設定說明

網站訂單流程現在支援：

1. 顧客送出訂單 → 自動寫入你的 **Google Sheet**（訂購單登記）
2. 同時可透過 **LINE** 通知你有新訂單（兩種方式，見下方）
3. 顧客在訂單成功頁可一鍵「複製訂單內容 → 開啟 LINE」把訂單貼給官方帳號（**這個不用任何設定，現在就能用**）

只要照下面步驟設定一次即可，全程免費、不需要租伺服器。

---

## 第一步：建立 Google Sheet

1. 到 [Google 試算表](https://sheets.google.com) 建立一份新的空白試算表，命名為「果然甜訂單」
2. 看網址列：`https://docs.google.com/spreadsheets/d/【這一長串就是ID】/edit`
3. 把那串 **試算表 ID** 複製起來，等一下要用

> 不用自己建工作表或標題列，程式第一次收到訂單時會自動建立「訂單」與「匯款回報」兩個工作表。

## 第二步：部署 Google Apps Script

1. 在剛剛的試算表中，點上方選單 **擴充功能 → Apps Script**
2. 把編輯器裡原有的程式碼全部刪掉，貼上本資料夾 `google-apps-script.gs` 的完整內容
3. 把最上面的 `SHEET_ID = '請貼上你的試算表ID'` 改成第一步複製的 ID
4. 點右上角 **部署 → 新增部署作業**
   - 類型選 **網頁應用程式**
   - 「執行身分」選 **我**
   - 「誰可以存取」選 **所有人**（一定要選這個，網站才能送資料進來）
5. 按「部署」，過程中會要求授權，一路允許即可
6. 複製產生的 **網頁應用程式網址**（`https://script.google.com/macros/s/XXXX/exec`）

> 💡 可以先在 Apps Script 編輯器裡執行 `testAppend` 函式測試，成功的話試算表會多一筆測試訂單。

## 第三步：把網址填回網站

打開專案裡的 `src/js/order-sync.js`，把第二步的網址貼到 `webhookUrl`：

```js
webhookUrl: 'https://script.google.com/macros/s/XXXX/exec',
```

存檔、部署網站，完成！之後每筆訂單和匯款回報都會自動登記到 Google Sheet。

## LINE 通知設定（選用）

### 方式 A：顧客貼單（零設定，已經可以用）

顧客下單成功後，頁面會出現「📋 複製訂單內容」和「💬 開啟 LINE 傳送訂單」按鈕，
顧客加入官方帳號（https://lin.ee/5bs67zb）後把訂單內容貼給你，你在 LINE 官方帳號後台就會收到。

### 方式 B：系統自動推播給你（需設定 LINE Messaging API）

設定後，每筆新訂單/匯款回報會**自動**推播到你的 LINE，不需要顧客動作：

1. 到 [LINE Developers](https://developers.line.biz/console/) 用你官方帳號的 LINE 商家帳號登入
2. 建立（或選擇既有的）**Messaging API** channel — 官方帳號後台「設定 → Messaging API」可直接啟用
3. 在 channel 的 **Messaging API 分頁**最下方，發行 **Channel access token（長期）**，複製起來
4. 在 **Basic settings 分頁**最下方找到 **Your user ID**（你自己的 userId，`U` 開頭），複製起來
5. 回到 Apps Script，把兩個值填入：
   ```js
   const LINE_CHANNEL_ACCESS_TOKEN = '貼上token';
   const LINE_ADMIN_USER_ID = '貼上你的userId';
   ```
6. **重新部署**：部署 → 管理部署作業 → 編輯（鉛筆）→ 版本選「新版本」→ 部署

> ⚠️ 注意：修改 Apps Script 程式碼後都要「新版本重新部署」才會生效，網址不會變。

### 加碼：Email 通知

不想設定 LINE API 的話，把 Apps Script 裡的 `NOTIFY_EMAIL` 填上你的信箱，新訂單就會寄信通知，最簡單。

## 常見問題

**Q：沒設定 webhookUrl 網站會壞掉嗎？**
不會。沒設定時訂單一樣會成立並存在顧客瀏覽器（後台 admin.html 可看），只是不會自動登記到 Google Sheet，主控台會提示一行警告而已。

**Q：怎麼確認串接成功？**
自己到網站下一筆測試訂單，幾秒內 Google Sheet 的「訂單」工作表就會多一列。

**Q：電話開頭的 0 會不見嗎？**
不會，程式已用文字格式寫入，`0912...` 會完整保留。
